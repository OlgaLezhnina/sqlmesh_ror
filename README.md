# ror-data
This is a toy sqlmesh project created by [Manuel Prinz](https://github.com/manuelprinz) and uploaded with his permission.
We use it for pair programming and coauthor the code.

The [ror data](https://zenodo.org/records/23500708) used for the project is the latest version of the data dump from the Research Organization Registry (ROR) on Zenodo, see also [Retrieve ROR data from Zenodo](https://ror.readme.io/docs/zenodo).

**100% AI-free: no AI technologies here.**
