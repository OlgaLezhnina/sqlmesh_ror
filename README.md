# sqlmesh-ror
This is a toy sqlmesh project created by [Manuel Prinz](https://github.com/manuelprinz) and uploaded with his permission.
We use it for pair programming and coauthor the code.

# Setting up
```bash
mise install
uv venv
uv sync
```
# ROR data
The project uses the [ROR data](https://zenodo.org/records/23500708), [this dataset](https://zenodo.org/records/23500708/files/v2.15-2026-10-20-ror-data.zip?download=1), which is the latest version of the data dump from the Research Organization Registry (ROR) on Zenodo. See also [Retrieve ROR data from Zenodo](https://ror.readme.io/docs/zenodo). 

**100% AI-free: no AI technologies here.**
